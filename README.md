# Dólar Amigo

Calculadora del "dólar amigo": el promedio entre compra y venta del dólar blue de Bahía Blanca, para tratos directos entre conocidos sin la diferencia que se queda la cueva.

**App:** https://imprezwag.github.io/dolaramigo/

## Autor

Idea, concepto y autoría: **Santiago** ([@Imprezwag](https://github.com/Imprezwag)).

## Cómo funciona

- Toma compra y venta del dólar blue de Bahía Blanca publicadas por [InfoDólar](https://www.infodolar.com/cotizacion-dolar-localidad-bahia-blanca-provincia-buenos-aires.aspx).
- Calcula el punto medio: (compra + venta) / 2.
- Un proceso automático guarda la cotización cada 10 minutos en la rama `data`.
- Los valores son de referencia.
